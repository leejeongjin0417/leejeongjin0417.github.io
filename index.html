어떤 앱인가

앱테크(리워드앱)를 여러 개 쓰다 보면 어제 뭘 했고 오늘 뭐가 남았는지를 놓치게 됩니다. 리워드 플래너는 등록한 앱들을 한 목록에 모아 두고, 매일 체크만 하면 성공률과 연속 기록이 쌓이도록 만든 도구입니다.

주요 기능

  • 일일 체크 목록 — 등록한 앱을 한 번 눌러 완료 표시, 자정에 자동 초기화
  • 리마인더 알림 — 전체 공통 시각 또는 앱마다 다른 시각으로 알림
  • 통계 — 성공률, 연속 기록(스트릭), 달력 히트맵
  • 추천 목록 — 직접 선별한 앱테크 앱 소개, 스토어 바로가기
  • 백업 · 복원 — 기기를 바꿔도 기록을 파일로 옮길 수 있음
기록은 기기에만 저장됩니다
